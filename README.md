# Portfolio — Jacopo

Site statique (HTML/CSS/JS, sans dépendance) déployé sur GitHub Pages.

- `site.config.json` : e-mail, GitHub, LinkedIn (les champs vides masquent le bouton correspondant).
- `npm test` : build dans `dist/` + vérifications (liens, SEO, confidentialité).
- `npm run serve` : aperçu local sur http://localhost:4173
- Déploiement : GitHub Actions (`.github/workflows/pages.yml`) à chaque push sur `main`.

Aucun code des dépôts privés n'est inclus.
